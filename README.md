# OOP Todo App

A small browser todo app built with HTML, CSS, and vanilla JavaScript.

## Features

- Add a new todo by typing text and pressing `Enter`.
- Toggle a todo by clicking on it.
- Remove completed todos with the `x` button.
- Save todos in `localStorage`.

## Files

- `index.html` - page markup.
- `styles.css` - app styles and animations.
- `main.js` - todo logic written with JavaScript classes.
